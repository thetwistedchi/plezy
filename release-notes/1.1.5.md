## Plezy Retrowave 1.1.5

### Updates (Android)
- When installing apps from Plezy Retrowave is not allowed yet, the update asks for it before downloading and carries on by itself once it is allowed, instead of having to be started a second time.
- After the download the update window stays open. If Android's install prompt does not appear, **Install** opens it again with the file already downloaded, without downloading it a second time.

### Playback (Android, Jellyfin and Emby)
- Videos in a format the device cannot decode in hardware (for example AV1 on an NVIDIA Shield) are converted by the server even at **Original** quality, instead of being decoded in software, where the picture fell far behind the sound.

### TV
- The focus ring of the back button is no longer cut off at the top edge of the screen.
- On the logs page, Left from the first button in the top bar moves to the back button.

### Logs
- **Save logs to a file** replaces uploading them. The upload went to the original Plezy project, whose developers can't help with this app. On Android TV the file is saved in the app's folder and the dialog shows the `adb pull` command to copy it.
- The startup error screen no longer offers an upload; **Copy details** stays.
