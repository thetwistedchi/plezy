## Plezy Retrowave 1.1.4

### Fixes
- **Fit height** reliably removes black bars baked into a video: it no longer drops the crop a few minutes in, tries again after dark scenes, and looks again when switched on mid-film.

### Startup
- Fewer duplicate requests at startup: library lists and Plex DVR checks are fetched once instead of twice, and Jellyfin users without Live TV access are no longer asked on every server check.
- No needless sync pass right after launch.
- Logs name the Retrowave version.
