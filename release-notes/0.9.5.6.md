## Plezy Retrowave 0.9.5.6

### Ratings
- The Trakt card opens the title's Trakt page instead of a "not found" page. When the Trakt score came from another source (e.g. MDBList), the card used to link to Trakt's id search, which can fail; it now looks up the title's page address first.

### Free on Plex
- New **Free on Plex** entry under the libraries in the sidebar (on phones in the library menu): Plex's free, ad-supported Movies & Shows, with all titles and Plex's own shelves, browsable like a library. Opening a title shows its details; the **Plex (free, with ads)** button plays it in Plex Web, since the service's copy protection and ads only work in Plex's own apps. Shown when a Plex server is connected.
