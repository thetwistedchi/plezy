## Plezy Retrowave 0.9.5.6

### Ratings
- The Trakt card opens the title's Trakt page instead of a "not found" page. When the Trakt score came from another source (e.g. MDBList), the card used to link to Trakt's id search, which can fail; it now looks up the title's page address first.

### Free on Plex
- New **Free on Plex** entry under the libraries in the sidebar (on phones in the library menu): Plex's free, ad-supported Movies & Shows, with all titles and Plex's own shelves, browsable like a library. Opening a title shows its details; the **Plex (free, with ads)** button plays it in Plex Web, since the service's copy protection and ads only work in Plex's own apps. Shown on Windows and macOS when a Plex server is connected, not on Android.

### Browser (Windows)
- New **Browser** entry in the sidebar: a built-in web browser with tabs, an address bar that searches with Ecosia by default (DuckDuckGo, Startpage, Brave Search, Google, Bing or a custom engine in the browser settings), back, forward and reload, and bookmarks shown on the new tab page.
- Only the tab on screen keeps running. Other tabs pause after 5 minutes (adjustable, or never) and continue when opened; tabs playing audio keep running, and all background tabs pause when memory runs low. Open tabs are restored after a restart (can be turned off).
- Built-in protection: pop-ups only open after a click (a blocked one can still be opened from the notice), notification requests are declined, passwords and form data are not saved, pages load over HTTPS when possible with a fallback offer when a site does not support it, local files and scripts can't be opened from the address bar, permissions like camera or location are asked for, and downloads are confirmed first with an extra warning for program files. Microsoft Defender SmartScreen warns about known dangerous sites and downloads.
- Shortcuts work inside pages too: Ctrl+T, Ctrl+W, Ctrl+L, Ctrl+Tab and Alt+Left/Right.
