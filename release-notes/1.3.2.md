## Plezy Retrowave 1.3.2

- **Keep top bar visible**: the top bar of libraries and the YouTube feed can stay in place while scrolling (Settings > Appearance). Each library can override this in Manage libraries (library menu > Top bar).
- **Podcast release dates** are read from the file name first (as podcast downloaders name their files), then from the server. This is used for the date under each episode, sorting by date and the New episodes row.
- **Audio player**: the lyrics, chapters, bookmarks and equalizer buttons keep their full size on narrower screens and move below the controls when there is no room beside them.
