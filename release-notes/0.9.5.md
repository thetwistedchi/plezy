## Plezy Retrowave 0.9.5

### Player
- Clicking the quality badge in the desktop player's bottom bar (e.g. `4K · HDR10`) opens the file info, the same page as in the player settings. Closing it returns to the video. When no file info is available, the badge is not clickable.
- Next to the quality badge, a second badge shows the playing audio format, e.g. `TrueHD Atmos 7.1`, `DTS-HD MA 5.1` or `AAC Stereo`. It follows audio track changes and also opens the file info.
- Both badges have a thinner outline and a lighter font, with the text centred.

### Mini player
- The back arrow and the back key work again on a page while a video is minimized in the mini player (e.g. going back from a movie's details page). Before, they did nothing until the player was closed.
- Keyboard focus moves to the page under the mini player when a video is minimized, so arrow keys, Tab and Enter work there right away.

### Details page
- Pressing the trailer button again while the trailer is still being searched no longer opens it twice.
